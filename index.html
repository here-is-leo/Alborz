// 01 — Features

Everything you need to inspect, edit, and protect.

هر چیزی که برای بررسی، ویرایش و محافظت نیاز داری.

From deep EXIF extraction to interactive GPS maps and professional PDF reports — Alborz is a complete metadata workstation.

از استخراج عمیق EXIF تا نقشه تعاملی GPS و گزارش PDF حرفه‌ای — البرز یک ایستگاه کاری کامل متادیتا است.

Deep Extraction

استخراج عمیق

Full EXIF, GPS, IPTC, XMP, ICC, and MakerNotes from images, videos, and audio. Auto-detects file type via magic bytes — not extensions.

EXIF، GPS، IPTC، XMP، ICC و MakerNotes کامل از تصویر، ویدیو و صدا. تشخیص خودکار نوع فایل با Magic Bytes — نه پسوند.

EXIF · IPTC · XMP · MakerNotes

Privacy Score (0–100)

امتیاز حریم خصوصی (۰–۱۰۰)

Every file gets an instant privacy score. Detects GPS coordinates, serial numbers, author info, and free-form comments that leak personal data.

هر فایل بیدرنگ یک امتیاز حریم خصوصی می‌گیرد. GPS، شماره سریال، اطلاعات نویسنده و متن‌های آزاد شناسایی می‌شوند.

Weighted Algorithm

Surgical Strip

حذف جراحی

Remove all metadata, or keep EXIF and strip only GPS. You choose exactly what gets deleted.

حذف کامل متادیتا، یا حفظ EXIF و فقط حذف GPS. دقیقاً انتخاب می‌کنی چه چیزی پاک شود.

// 04 — Command Line

Automate with a proper CLI.

با یک CLI واقعی خودکار کن.

Three commands cover 90% of use cases: extract, score, and strip. Chain with pipes. Script with bash. Perfect for CI/CD.

سه دستور ۹۰٪ کاربردها را پوشش می‌دهند: extract، score و strip. با pipe ترکیب کن. با bash اسکریپت بنویس. عالی برای CI/CD.

alborz — powershell

// 06 — FAQ

Frequently asked questions.

سؤالات متداول.

Do my files get uploaded anywhere? آیا فایل‌هایم جایی آپلود می‌شوند؟
No. In self-hosted mode (the EXE or python launcher.py), everything runs locally on your machine. The server binds to 127.0.0.1 — it's not accessible from outside your computer.
خیر. در حالت self-hosted (EXE یا python launcher.py)، همه‌چیز محلی روی دستگاه شما اجرا می‌شود. سرور فقط روی 127.0.0.1 گوش می‌دهد — از خارج از کامپیوتر شما قابل دسترس نیست.
What file types does Alborz support? البرز از چه فرمت‌هایی پشتیبانی می‌کند؟
Images (JPEG, PNG, TIFF, HEIC, WebP, GIF, BMP), video (MP4, MOV, AVI, MKV, WebM), and audio (MP3, WAV, FLAC, OGG, AAC). RAW support for CR2, NEF, ARW, DNG.
تصاویر (JPEG, PNG, TIFF, HEIC, WebP, GIF, BMP)، ویدیو (MP4, MOV, AVI, MKV, WebM) و صدا (MP3, WAV, FLAC, OGG, AAC). پشتیبانی RAW برای CR2, NEF, ARW, DNG.
Can I keep the EXIF but remove only GPS? می‌توانم EXIF را نگه دارم و فقط GPS را پاک کنم؟
Yes — this is one of the most-requested features. Use the "Strip GPS Only" button in the UI, or alborz strip photo.jpg --keep EXIF from the CLI.
بله — این یکی از پرتقاضاترین قابلیت‌ها است. از دکمه "فقط حذف GPS" در رابط وب استفاده کن، یا alborz strip photo.jpg --keep EXIF در CLI.
How accurate is the privacy score? امتیاز حریم خصوصی چقدر دقیق است؟
It's a weighted heuristic, not a guarantee. GPS presence alone drops the score by 30 points. The algorithm is open source — you can inspect and modify it in metatool/core/editor.py.
یک هیوریستیک وزن‌دار است، نه تضمین. حضور GPS به‌تنهایی ۳۰ امتیاز کم می‌کند. الگوریتم متن‌باز است — می‌توانی در metatool/core/editor.py بازبینی و تغییرش دهی.
Does it work on macOS or Linux? روی macOS یا Linux کار می‌کند؟
The CLI and Web UI work on all platforms. The standalone EXE is Windows-only for now. macOS/Linux binaries are planned for v1.1.
CLI و رابط وب روی همه پلتفرم‌ها کار می‌کنند. EXE مستقل فعلاً فقط ویندوز است. باینری macOS/Linux برای v1.1 برنامه‌ریزی شده.
Is the video metadata extraction slow? استخراج متادیتای ویدیو کند است؟
It uses ffprobe which is fast for metadata. Requires FFmpeg installed system-wide. For images and audio, no external dependencies are needed.
از ffprobe استفاده می‌کند که برای متادیتا سریع است. نیاز به FFmpeg نصب‌شده روی سیستم دارد. برای تصویر و صدا، هیچ وابستگی خارجی لازم نیست.
