## 🌐 English

</div>

<div align="center">
  <p><i>"Named after the <b>Alborz mountain range</b> in Iran — a symbol of permanence, depth, and layered strength. Just like the metadata layers hidden in your files."</i></p>
</div>

<br>

**Alborz** is a modern, production-grade metadata toolkit that goes far beyond a simple EXIF viewer. It **extracts**, **analyzes**, **scores**, **edits**, and **strips** metadata from images, videos, and audio files — while putting **privacy first**.

<br>

### ✨ Why Alborz?

<table>
<tr>
<td width="50%" valign="top">

#### 🔍 Deep Extraction
- Full **EXIF, GPS, IPTC, XMP, MakerNotes**
- Images, videos, and audio
- Auto file-type detection (magic bytes, not extensions)
- Original timestamps, device model, lens data
- GPS coordinates + reverse geocoding

</td>
<td width="50%" valign="top">

#### 🛡️ Privacy First
- **Privacy Score** from 0–100
- Identifies sensitive tags (GPS, serials, author)
- Full or **selective** metadata stripping
- Client-side ready (WASM architecture)
- Self-hosted = no file leaves your device

</td>
</tr>
<tr>
<td width="50%" valign="top">

#### 🎯 Professional Tools
- **Interactive GPS map** (OpenStreetMap)
- **Batch processing** with ZIP export
- **Metadata editor** with visual diff
- **Two-file comparison** (A vs B)
- **Professional PDF reports**

</td>
<td width="50%" valign="top">

#### 🌍 Everywhere
- 💻 **CLI** — for automation and scripting
- 🌐 **Web UI** — beautiful Persian-first interface
- 📦 **Standalone EXE** — Windows, no install needed
- 🔌 **REST API** — for integration
- 🐳 **Docker** — coming soon

</td>
</tr>
</table>

### 🚀 Quick Start

#### 🪟 Option 1 — Standalone EXE (Windows)

Download `Alborz.exe` from [**Releases**](https://github.com/here-is-leo/alborz/releases) and double-click. The browser opens automatically.

```bash
Alborz.exe
```

#### 🐍 Option 2 — From Source (All Platforms)

```bash
# Clone
git clone https://github.com/here-is-leo/alborz.git
cd alborz

# Setup
python -m venv venv
source venv/bin/activate        # Linux/macOS
venv\Scripts\activate            # Windows
pip install -r requirements.txt

# Run
python launcher.py
```

#### ⚡ Option 3 — CLI Only

```bash
# Extract metadata
python -m Alborz.cli.main extract photo.jpg

# Privacy score
python -m Alborz.cli.main score photo.jpg

# Strip all metadata
python -m Alborz.cli.main strip photo.jpg

# Selective strip (keep EXIF, remove GPS)
python -m Alborz.cli.main strip photo.jpg --keep EXIF
```

## 📚 Documentation

<details>
<summary><b>🔍 &nbsp;Supported File Formats — فرمت‌های پشتیبانی‌شده</b></summary>
<br>

| Category | Formats |
|:---------|:--------|
| **📷 Images** | `JPEG` · `PNG` · `TIFF` · `HEIC` · `HEIF` · `AVIF` · `WebP` · `GIF` · `BMP` · `RAW` (CR2, NEF, ARW, DNG) |
| **🎬 Video** | `MP4` · `MOV` · `AVI` · `MKV` · `WebM` · `FLV` · `WMV` · `M4V` |
| **🎵 Audio** | `MP3` · `WAV` · `FLAC` · `OGG` · `AAC` · `M4A` · `Opus` |
| **📄 Documents** | `PDF` *(in progress)* |

</details>

<details>
<summary><b>🎨 &nbsp;Metadata Standards — استانداردهای متادیتا</b></summary>
<br>

- **EXIF** — Camera settings, GPS, timestamps
- **IPTC** — Editorial info, keywords, copyright
- **XMP** — Adobe extensible metadata
- **ICC** — Color profiles
- **MakerNotes** — Manufacturer-specific tags
- **QuickTime Atoms** — Video container metadata
- **ID3v2 / Vorbis Comments** — Audio tags

</details>

<details>
<summary><b>🔒 &nbsp;Privacy Score Algorithm — الگوریتم امتیاز حریم خصوصی</b></summary>
<br>

The privacy score (0–100) is computed by subtracting weighted penalties:

| Tag | Weight | Reason |
|:----|:------:|:-------|
| GPS coordinates | −30 | Exact location |
| Artist / Copyright | −15 | Personal identity |
| Serial numbers | −15 | Device fingerprinting |
| DateTimeOriginal | −10 | Timestamp correlation |
| Model / Make | −8 | Device identification |
| UserComment | −5 | Free-form text |
| Software | −3 | Workflow exposure |

**Levels:** 🟢 Safe (80–100) · 🟡 Medium (50–79) · 🔴 High Risk (0–49)

</details>

<details>
<summary><b>🧩 &nbsp;API Reference — مرجع API</b></summary>
<br>

| Endpoint | Method | Description |
|:---------|:------:|:------------|
| `/api/extract` | `POST` | Extract all metadata from a file |
| `/api/strip` | `POST` | Remove metadata (full or selective) |
| `/api/edit` | `POST` | Edit specific tags |
| `/api/batch/extract` | `POST` | Batch extract |
| `/api/batch/strip` | `POST` | Batch strip → ZIP |
| `/api/compare` | `POST` | Compare two files |
| `/api/geo` | `POST` | Extract GPS + reverse geocode |
| `/api/report/pdf` | `POST` | Generate PDF report |
| `/api/tag/{name}` | `GET` | Tag description |
| `/api/version` | `GET` | Version info |

**Interactive docs** available at `http://localhost:8000/docs` (Swagger UI).

</details>
